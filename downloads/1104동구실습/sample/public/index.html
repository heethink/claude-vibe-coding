기상청 API 설정

기상청 공공데이터포털(data.go.kr)에서 발급받은 단기예보 Open API 인증키를 등록하면 실시간 기상 데이터를 직접 받아옵니다.

입력한 키는 브라우저 로컬 저장소(LocalStorage)에 안전하게 저장됩니다.
데모(체험) 모드 사용하기

API 키 없이도 사이트의 모든 기능을 테스트할 수 있습니다.

💡 기상청 API 키 무료 발급 방법 (3분 소요)

  1. 공공데이터포털(data.go.kr) 회원가입 및 로그인
  2. 통합검색창에 "기상청_단기예보 ((구)동네예보) 조회서비스" 검색
  3. [활용신청] 클릭 후 즉시 승인된 일반 인증키(Encoding/Decoding) 복사 후 위 입력창에 붙여넣기

데이터 제공: 대한민국 기상청(KMA) 공공데이터포털

위경도-기상청 격자(LCC 투영) 실시간 좌표 변환 알고리즘 적용
