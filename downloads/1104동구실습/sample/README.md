# ⛅ 대한민국 기상청 날씨 웹 애플리케이션 (KMA Weather Web)

공공데이터포털의 **기상청 단기예보 Open API**를 연동하여 전국 원하는 지역의 실시간 날씨와 24시간 예보를 확인할 수 있는 반응형 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **전국 시/도 및 시/군/구 지역 선택**:
   - 서울, 경기, 부산, 제주 등 17개 광역시·도 및 대표 시·군·구 상세 선택 지원
   - 자주 찾는 주요 거점 원클릭 바로가기 칩 (서울 종로/강남, 부산 해운대, 인천 송도, 제주공항 등)
2. **GPS 내 위치 기반 실시간 날씨**:
   - Geolocation API를 통해 현재 사용자 위치의 위·경도를 실시간 기상청 격자(nx, ny)로 변환(LCC 투영 공식)하여 날씨 조회
3. **상세 기상 지표 시각화**:
   - 현재 기온(℃), 최고/최저 기온, 체감 온도
   - 날씨 상태(맑음, 구름많음, 흐림, 비, 눈 등) 및 맞춤형 SVG 날씨 아이콘
   - 습도(%), 강수확률(%), 풍속(m/s), 기상청 격자 좌표(X, Y)
4. **24시간 시간대별 날씨 예보**:
   - 시간대별 기온 변화 및 강수확률을 가로 스크롤 카드로 직관적 확인
5. **체험 데모(Mock) 모드 내장**:
   - 공공데이터포털 API 키가 아직 없거나 승인 대기 중이어도 즉시 사이트의 모든 UI와 기능을 실시간처럼 둘러보고 테스트 가능
   - 웹 화면의 **[API 키 설정]** 팝업을 통해 직접 발급받은 키를 등록하거나 `.env` 파일에 저장 가능

## 🚀 빠른 시작 (실행 방법)

### 1. 패키지 설치
```bash
npm install
```

### 2. 서버 실행

## 🔑 기상청 API 키 발급 및 등록 방법

1. [공공데이터포털 (data.go.kr)](https://www.data.go.kr)에 접속 후 회원가입/로그인합니다.
2. 검색창에 **`기상청_단기예보 ((구)동네예보) 조회서비스`**를 검색합니다.
3. **[활용신청]** 버튼을 클릭합니다 (신청 즉시 자동 승인 처리됩니다).
4. 마이페이지 > 데이터활용 > 오픈API > 개발계정에서 승인된 서비스의 **일반 인증키(Encoding 또는 Decoding)**를 복사합니다.
5. 등록 방법 (아래 둘 중 하나):
   - **방법 A (웹 UI)**: 실행된 웹사이트 우측 상단 **[API 키 설정]** 버튼을 눌러 키를 붙여넣고 저장합니다.
   - **방법 B (.env 파일)**: 프로젝트 루트의 `.env` 파일에 입력합니다:
     ```env
     KMA_SERVICE_KEY=여기에_발급받은_인증키_입력
     ```

*(공공데이터포털 API 키는 발급 직후 동기화까지 약 1~2시간 정도 소요될 수 있으며, 그동안에는 사이트 내 **데모 모드**를 켜두고 편리하게 테스트할 수 있습니다.)*

## 📁 프로젝트 구조

```
sample/
├── public/                  # 프론트엔드 정적 파일
│   ├── index.html           # 메인 대시보드 마크업
│   ├── style.css            # 반응형 글래스모피즘 스타일시트
│   └── app.js               # UI 인터랙션, 좌표 변환 및 API 통신
├── data/
│   └── regions.js           # 전국 17개 시도/시군구 및 격자 좌표 매핑
├── utils/
│   └── gridConverter.js     # 기상청 위경도 <-> 격자(nx, ny) LCC 투영 알고리즘
├── services/
│   └── kmaService.js        # 기상청 단기예보/초단기실황 API 통신 및 모의 데이터 생성
├── server.js                # Express 백엔드 서버 & API 프록시
├── package.json
└── .env                     # 환경변수 (API Key, Port)
```
